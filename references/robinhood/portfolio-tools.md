# Portfolio & Account Tools Reference

Source: https://robinhood.com/us/en/support/articles/trading-with-your-agent/

## Portfolio & Account Tools

| Tool | Description |
|------|-------------|
| `get_accounts` | View all your Robinhood accounts |
| `get_portfolio` | Get snapshot of portfolio: total value, values by asset class, real-time buying power |
| `get_realized_pnl` | View realized P&L over a custom time window, broken down by asset class |
| `get_pnl_trade_history` | View trade-by-trade realized P&L history |
| `search` | Find a company name or partial name to a ticker |

## Watchlist Tools

| Tool | Description |
|------|-------------|
| `get_watchlists` | List user's watchlists |
| `get_watchlist_items` | List symbols in a specific watchlist |
| `get_option_watchlist` | Load an options watchlist |
| `get_popular_watchlists` | Discover Robinhood lists (like "100 most popular") |
| `create_watchlist` | Make a new custom watchlist |
| `update_watchlist` | Rename or update a watchlist's name/description |
| `follow_watchlist` | Follow a Robinhood list |
| `unfollow_watchlist` | Stop following a Robinhood list |
| `add_to_watchlist` | Add stocks/crypto/indexes to a watchlist |
| `remove_from_watchlist` | Remove stocks/crypto/indexes from a watchlist |
| `add_option_to_watchlist` | Add an options contract to a watchlist |
| `remove_option_from_watchlist` | Remove an options contract from a watchlist |

## Scanner Tools

| Tool | Description |
|------|-------------|
| `get_scans` | List your saved scans |
| `get_scanner_filter_specs` | List every available scanner filter and how to use it |
| `create_scan` | Create a new scan from a starting preset or with custom filters |
| `run_scan` | Run a saved scan and get live market results |
| `update_scan_filters` | Change the filters on an existing saved scan |
| `update_scan_config` | Change result sorting on a saved scan |

## Option Tools

| Tool | Description |
|------|-------------|
| `get_option_level_upgrade_info` | Get link to apply for options trading access |
| `get_option_historicals` | Get OHLC price bars for option contracts across a time range |
| `get_option_chains` | Load option chains |
| `get_option_instruments` | Load option contracts filtered by expiry, strike, or type |
| `get_option_quotes` | Get real-time quotes for option contracts |
| `get_option_positions` | View open/closed options positions |
| `get_option_orders` | Get options order history |
| `review_option_order` | Simulate an options order with pre-trade alerts |
| `cancel_option_order` | Cancel an open options order |
| `place_option_order` | Place a real options order |
